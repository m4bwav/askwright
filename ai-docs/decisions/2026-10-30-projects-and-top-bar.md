# 2026-10-30: projects, timestamps and the top bar (0.8.0)

Small calls made without asking, per the continue prompt. Each can be reversed in one place.

- P1. **Project records live in the user-wide registry**, `<ASKWRIGHT_HOME or ~/.askwright>/projects/<slug>.json`, one atomic file per project, beside `sessions/` and `session-state/`. Not in the set: a project spans many sets and outlives them. The set keeps its existing `project` field (name or `{name, path}`); the slug of the name is the join key, so no set needs rewriting.
- P2. **Records are created implicitly** when a set naming a project is registered (by `new`, `serve` or `register`), with the set's `path` added to `dirs`. `ask.py project` adds the description and repositories. A project named only by sets still gets a page (built from its sets) even without a record file.
- P3. **"Last worked on"** is the newest of the record's `updated` and each set's `last_worked` (its `updated` and its last answer, added, done or submit event). No separate write on every answer.
- P4. **Timestamps migrate by fallback, not by rewrite**: a set or question without `created`/`updated` reads questions.json's modification time (questions take the set's). Existing sets are never rewritten just to add times; the next `add` or `close` stamps them. `add --replace` keeps a question's `created`.
- P5. **The project page is served by both the dashboard and every question server** (`/projects/<slug>`), so the project link in a question page's top bar works without the dashboard running. Opening a set from it uses the same `/api/open` as the dashboard.
- P6. **Top bar**: one row. Project (small caps, a link) over the title, each one line with an ellipsis and the full title on hover; two pills (`3 / 7` and `2 done · 5 left`) that never wrap; then chips of one height. Under 70rem (first tried 56rem: at 1000 px the title kept only two words) the secondary chips (back link, All sessions, Copy continue prompt, Keys) move into a More menu: app.js moves the same elements so ids, handlers and tests keep working. Under 40rem the bar takes two rows: heading, then pills and chips; the count pill drops (the track shows it).
- P7. **Relative times** come from `Intl.RelativeTimeFormat` in a shared `time.js`; every time is a `<time>` element with the exact local time in `title`.
- P8. **The "Welcome back" notice** uses a neutral info style (surface colour, accent edge) instead of the warning colours; added/closed-question notices keep the warning style.
- P9. **Dashboard grouping**: a Projects strip (each project linked, with its open count) above the lists and a linked project label on each card, rather than regrouping the cards; the existing pending-first sort stays.
- P10. **Visual tests** are a separate file, `tests/test_visual.py`, so the stdlib suite runs alone and `test_page.py` keeps its behaviour focus. Screenshots go to `tests/screenshots/` (git-ignored) or `ASKW_SHOTS`.
